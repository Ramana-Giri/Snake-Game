# 🐍 Snake Game  
A simple Snake Game built using **HTML**, **CSS**, and **JavaScript**.

![Snake Game](https://github.com/user-attachments/assets/518ed0bd-ab9b-4aa1-9bcb-1e03d09c3bf9)

## 🎮 How to Play

- Press any key to **start the game**
- Use **arrow keys** to control the snake (⬆️ ⬇️ ⬅️ ➡️)
- **Eat the red food** to grow in length and increase your score
- Avoid hitting the **walls** — if you do, it's **Game Over**
- To **restart**, press any key again
